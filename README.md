# Interactive Pricing Calculator

A responsive web application that calculates the total cost of a purchase based on unit price and quantity, including discounts and tax.

## Features

- Calculate the subtotal from unit price and quantity.
- Apply a 10% discount when the quantity is 10 or more.
- Calculate 15% tax after applying any discount.
- Display a breakdown of the subtotal, discount, tax, and final total.
- Validate user inputs and reject invalid prices or fractional quantities.
- Responsive layout for desktop and mobile screens.
- Keyboard-friendly form submission and visible focus indicators.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter a unit price and quantity.
5. Click **Calculate Total** to view the price breakdown.

## Pricing Rules

- **Subtotal:** Unit price × quantity
- **Discount:** 10% when the quantity is 10 or more; otherwise, no discount.
- **Tax:** 15% of the subtotal after the discount.
- **Final Total:** Discounted subtotal + tax
